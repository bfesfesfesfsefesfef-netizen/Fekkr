# فَكَّر — دليل النشر على Render

## محتوى المجلد
```
render-deploy/
├── package.json      # تعريف المشروع (بدون حزم خارجية)
├── server.js         # خادم Node يخدم الواجهة + يحقن المفتاح من متغير البيئة
├── render.yaml       # Blueprint — إعدادات النشر التلقائي
├── .gitignore        # يستبعد key.txt والكتب الضخمة والنسخ الاحتياطية
├── README.md         # هذا الملف
└── public/
    ├── index.html    # الواجهة الكاملة (فيها placeholder للمفتاح)
    ├── sw.js         # عامل الخدمة — العمل بدون اتصال
    └── books/txt/    # نصوص الكتب المستخرجة (4MB) + manifest.json
```

## قبل النشر — مهم
- **لا قاعدة بيانات**: بيانات الطالب في متصفحه (localStorage/IndexedDB) — تصميم مقصود للخصوصية.
- **لا كتب PDF**: 438MB لا تناسب الاستضافة المجانية؛ الامتحان والمعلم يقرآن من النص (4MB).
- **المفتاح ليس في المستودع**: `index.html` فيه `window.__SERVER_KEY__ = "__GEMINI_KEY__"`، والخادم يستبدله بقيمة `GEMINI_KEY` من متغير البيئة وقت الإرسال.

##خطوات النشر

### 1) GitHub
1. افتح github.com → سجّل الدخول → **New repository** → الاسم `fekkr` → **Public** → Create.
2. ارفع **محتوى مجلد `render-deploy` كاملًا** إلى جذر المستودع (اسحب الملفات لصفحة الرفع).
3. تأكد `.gitignore` يمنع `key.txt` والـPDFs.

### 2) Render
1. render.com → سجّل الدخول بحساب GitHub.
2. **New → Blueprint** → اختر مستودع `fekkr` → مكتبة `render.yaml` تلقائيًا.
3. عند خطوة **Environment** بيطلب قيمة `GEMINI_KEY` (لأن `sync: false`):
   - الصق مفتاح Gemini الجديد (من `key.txt` عندك).
   - لا تحطه في المستودع أبدًا.
4. اضغط **Apply** → انتظر الحالة **Live** (دقيقتان).
5. الرابط: `https://fekkr.onrender.com`.

### 3) تحقق
- افتح الرابط على الهاتف.
- جرّب: مولّد الامتحانات ← اختر رياضيات ← اقرأ جدول المحتويات ← ولّد الامتحان ← صحّح.
- جرّب تبديل اللغة (عربي/English).
- ⚠️ الخطة المجانية تنام بعد عدم استخدام — أول فتح ياخد ~20 ثانية.

## استكشاف أخطاء
- **"تعذّر الوصول لمفتاح Gemini"**: تأكد `GEMINI_KEY` محطوط في Environment في Render وهو مفتاح سليم (جرّبه محليًا).
- **404 على الكتب**: تأكد مجلد `public/books/txt` مرفوع كاملًا (23 ملفًا).
- **الصفحة بيضاء**: افتح Console في المتصفح وشوف الخطأ.
